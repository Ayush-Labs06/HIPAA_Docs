# Sources and guidance (where the real answers live)

Use primary sources. Blogs (including this repo) are for orientation. Last checked: **November 2026**.

**A note on the links.** The `hhs.gov` site refused automated page fetches (HTTP 403) when I checked, so I confirmed those paths from search results that returned the exact page titles, not by loading them. The eCFR, Federal Register, govinfo, NIST (800-66r2, 800-30r1, CSF), healthit.gov and 405d pages loaded directly. The FTC, NIST 800-88r2, hhscyber.hhs.gov, CMS and court links come from search results too. If a link has moved, search the page title shown.

## Rule of thumb for currency

Before using any fact from this repo at work, check:
1. Is the source primary (the CFR, the Federal Register, a court, an HHS page)?
2. Has it changed since November 2026? Penalty amounts are adjusted yearly; proposed rules move.
3. Does a state law or the customer's BAA add something stricter?
